1. Contexto industrial

Un horno de reflujo SMD calienta de forma controlada las tarjetas electrónicas para fundir la pasta de soldadura y formar uniones eléctricas y mecánicas. La temperatura debe regularse para evitar perfiles térmicos inadecuados.

Planta

Zona térmica equivalente del horno.

Sensor

Mide la temperatura de la zona controlada.

Controlador

Control PI que compara la referencia con la medición.

Actuador

Calentador eléctrico con potencia limitada entre 0 y 100 %.

2. Modelo matemático

Se utiliza un modelo concentrado de balance de energía. La temperatura se considera uniforme en una zona térmica equivalente.

Cth dT/dt = Pmaxu(t) − [T(t) − Ta]/Rth + Qd(t)

En variables de desviación y sin perturbación, la función de transferencia es:

G(s) = ΔT(s)/ΔU(s) = PmaxRth / (RthCths + 1) = K/(τs+1)
Ganancia:
K = PmaxRth
Constante de tiempo:
τ = RthCth

Los valores iniciales son supuestos de simulación para estudiar el método. No representan especificaciones certificadas de un horno comercial.

3. Controlador PI

e(t) = Tref(t) − T(t)
u(t) = Kpe(t) + Ki ∫e(t)dt

La señal de control se limita al intervalo 0 ≤ u ≤ 1. La integración condicional anti-windup evita seguir acumulando el error cuando el actuador está saturado y el error empuja en la misma dirección.

Para realimentación unitaria, la función de transferencia de lazo cerrado es:

TCL(s) = K(Kps + Ki) / [τs² + (1+KKp)s + KKi]

4. Simulador interactivo

El simulador usa integración de Euler con paso de 2 segundos y las mismas ecuaciones y regla anti-windup del script de GNU Octave. El caso inicial no incluye perturbación, para permitir una comparación directa.

5. Resultados y análisis

En la configuración inicial, el lazo abierto aplica una potencia fija calculada para el punto nominal, pero no corrige desviaciones. El lazo cerrado modifica la potencia mediante el PI para reducir el error de temperatura.

La estabilidad teórica del modelo lineal se evalúa a partir de los polos de la función de transferencia de lazo cerrado. Para los parámetros iniciales del proyecto, el denominador es 9600s² + 33s + 0.08 y sus polos tienen parte real negativa.

La comparación definitiva debe realizarse ejecutando el script de GNU Octave y esta página con idénticos parámetros, tiempo de simulación, condición inicial y perturbación. Las diferencias numéricas pequeñas pueden deberse al redondeo.
